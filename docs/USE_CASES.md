# 2.3.3. Description of Use Cases

| # | Use Case Name | Definition |
|---|---------------|------------|
| 1 | Configure Widget Settings | Admin can customize the chat widget appearance and behavior including greeting message, default suggested questions, and VAPI voice assistant configuration (assistant ID and phone number). |
| 2 | Upload Knowledge Document | Admin can upload company documentation or FAQs to the knowledge base. Files are processed, text extracted, and vectorized for AI agent to provide accurate responses. |
| 3 | Manage Plugins | Admin can integrate and configure third-party services (e.g., VAPI for voice calls) by managing plugin settings and API credentials stored in AWS Secrets Manager. |
| 4 | Manage Team Members | Admin can add, remove, or modify team member roles and permissions within the organization using Clerk's organization management. |
| 5 | Manage Subscription | Admin can view and update the organization's subscription plan, which enables or disables AI agent auto-responses in conversations. |
| 6 | View Conversations | Admin and TeamMember can view all customer support conversations, including conversation status (unresolved, escalated, resolved), customer information, and message history. |
| 7 | Chat with Customer | Admin and TeamMember can respond to customer messages, take over from AI agent when conversation is escalated, and provide human support. |
| 8 | Update Conversation Status | Admin and TeamMember can change conversation status between unresolved (AI responding), escalated (needs human attention), or resolved (closed). |
| 9 | Create Contact Session | Customer can authenticate in the widget by providing name and email. A temporary contact session is created with 24-hour expiration and browser metadata captured. |
| 10 | Start Conversation | Customer can initiate a new support conversation through the chat widget, creating a conversation thread linked to their contact session. |
| 11 | Send Message | Customer can send text messages to the AI agent or human support staff through the chat interface. |
| 12 | View Conversation History | Customer can view their previous messages and responses within the current conversation session. |
| 13 | View AI Responses | Customer receives and views automated responses generated by the AI agent using knowledge base and conversation context. |
| 14 | Select Suggested Questions | Customer can click on pre-configured suggested questions displayed in the widget to quickly start common inquiries. |
| 15 | Make Voice Call | Customer can initiate a voice call with VAPI voice assistant if the feature is enabled and configured by the organization admin. |
| 16 | Sign In | Admin/TeamMember authenticate through Clerk with organization-based JWT tokens. Customer authenticates through temporary contact session with name and email. |
